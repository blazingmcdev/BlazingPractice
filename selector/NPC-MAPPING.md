# Mapping from the supplied NPCs.yml

This is a concise reference, not a replacement for the external NPC plugin's `npcs.yml`.

- Survival NPC: `mv tp {player} w:world --unsafe`
- FFA NPC: `mv tp {player} w:practice --unsafe`
- Discord NPC: clickable URL `https://discord.gg`
- SylixCloud NPC: clickable URLs `https://sylixcloud.com` and `https://discord.gg/bSWnZ9ftmS`

The selector buttons run the same configured actions. Keep the original NPC plugin and its `npcs.yml` in place; BlazingPractice does not need to copy or overwrite it.
